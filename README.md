# purinlabo.com

Purin_Labo の公式サイト。ゲーム・アプリ・無料Webツールを1か所に置いています。

Webツールはすべてブラウザの中だけで動きます。**選んだファイルがサーバーへ送信されることはありません。**

## 構成

- [Astro](https://astro.build/) / TypeScript（静的出力）
- Cloudflare Pages
- サーバー・データベース・ログインなし

## 開発

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # dist/ に出力
```

## ライセンス

コードの著作権は Purin_Labo に帰属します。サイトに掲載している文章・画像の転載はご遠慮ください。
